# `<version> h<rev> <arch> <digest-ref>` — the hand-off from `make image` to
# runtime_version.image_digest (design §5). Append-only; the control
# plane resolves the LAST matching line for a (version, rev, arch).
#
# Builds are reproducible: the base image is pinned by digest, every
# timestamp is fixed (SOURCE_DATE_EPOCH=0) and, from h3, the builder is one
# pinned BuildKit (`make builder`), so rebuilding a (version, rev, arch) on any
# host of that arch gives the same digest and `make image` adds no line. A new
# line for an existing (version, rev, arch) means an input changed without a
# rev bump. Before h3 each host's own `docker build` was used and hosts of the
# same arch disagreed, so an h1/h2 line reproduces only on the host that built
# it.
